# Библиотека Ибн Каййима · Android (Kotlin/Compose)

Нативная бесплатная читалка, **без рекламы и регистрации**, для Android 8+.

## Что реализовано в v0.1

- Каталог четырёх русскоязычных PDF c официальных страниц IslamHouse.
- Загрузка исходных PDF непосредственно с `d1.islamhouse.com` в приватное хранилище приложения.
- Офлайн-чтение через Android `PdfRenderer` после первой загрузки.
- Сохранение страницы чтения, отдельная закладка для каждого издания.
- Поиск по названию и описанию книги (НЕ поиск по тексту PDF).
- Увеличение до 300%, кнопки перелистывания страниц, информация об источниках и переводчиках.
- Нативный интерфейс Jetpack Compose в тёплом бумажном минимализме.

**Не реализовано:** полнотекстовый поиск по PDF, извлечение и структурирование глав, жестовое масштабирование, автоматические обновления изданий, импорт сторонних файлов и проверка устройства на Android. Эта версия — работающий исходный проект, но не протестированный на реальном телефоне APK.

## Правовая модель

Текстов произведений нет внутри APK. PDF скачивается на телефон пользователя непосредственно с IslamHouse и показывается без модификации. В каталоге и разделе «О библиотеке» указаны автор, переводчики, источник. IslamHouse публикует правила повторного использования контента, в том числе в приложениях: https://github.com/IslamHouse-API/multilingual-quran-hadith-islamic-content-database-api-hub

Это не означает, что все русские переводы повсюду свободны от авторского права: перед публикацией необходима окончательная проверка прав конкретных изданий и письменное уточнение спорных случаев. «Избранное» (Умма) и «Фаваид» (русский перевод Сорокоумовой) не включены.

## Сборка

В GitHub: создайте отдельный репозиторий, загрузите содержимое этого каталога в корень ветки `main`, откройте Actions → Android APK → запустите workflow (или дождитесь push-сборки). На странице успешного запуска в Artifacts скачайте `IbnQayyimLibrary-debug-apk`; внутри ZIP будет APK для установки вручную.

В Android Studio: открыть каталог как проект, дождаться синхронизации и выполнить **Build → Build APK(s)**.

CLI с установленным Gradle 8.10.2 / JDK 17 / Android SDK 35:

```
gradle :app:testDebugUnitTest :app:assembleDebug
```

Локальная проверка чистой Kotlin-логики (без Android SDK):

```
kotlinc app/src/main/java/com/ibnqayyim/library/BookCatalog.kt dev-tests/CatalogSmokeTest.kt -include-runtime -d /tmp/ibn-qayyim-smoke.jar
java -jar /tmp/ibn-qayyim-smoke.jar
```

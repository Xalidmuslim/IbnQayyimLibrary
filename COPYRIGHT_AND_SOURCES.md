# Правовой статус материалов и источники

Последняя проверка общих условий: 22 октября 2026.

Этот проект **не содержит PDF книг и не публикует их копии**. Для чтения пользователь скачивает оригинальные PDF непосредственно с официальной инфраструктуры IslamHouse (HTTPS). Исходный PDF отображается системой Android без изменений. Приложение показывает атрибуцию.

## Условия IslamHouse

Исходный публичный документ разработчиков:
https://github.com/IslamHouse-API/multilingual-quran-hadith-islamic-content-database-api-hub

На 22.10.2026 в README разрешены публикация, хранение офлайн и использование исходного контента в приложениях, в том числе некоммерческих, с указанием источников, сохранением неизменённого текста и метаданных. Лицензия MIT в этом репозитории относится к **техническому коду**, а не автоматически ко всем переводам.

Официальный контакт для письменного уточнения прав: admin@islamhouse.com.
